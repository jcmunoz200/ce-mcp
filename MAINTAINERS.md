## Responsibilities

- Keep the scope focused on the MCP server and its backends.
- Review design proposals and ADRs.
- Protect the project's legal and ethical boundaries.
- Choose the implementation license before code contributions open.
- Maintain the documentation site and CI.
- Handle security reports confidentially.

## Becoming a maintainer

There is no formal process during the design phase. When code contributions
open, maintainership will be offered to contributors with sustained,
high-quality work and good judgment, by consensus of the existing maintainers.
