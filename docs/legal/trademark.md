The name "Cheat Engine" is used only to describe interoperability: the project
drives Cheat Engine through its Lua API and targets Cheat Engine 7.7. This is a
nominative use of a product name. It does not claim ownership of the mark.

The project name `ce-mcp` is not a Cheat Engine product name and does not imply
that the project is official.
